How It Works

Three simple steps to participate in a college election.

1. Login

Sign in securely using your College ID and password.

2. Vote

View the active election, select a candidate, and cast your vote once.

3. Results

View election results after voting officially closes.

Platform Features

Core functionality behind the VoteEase experience.

Password Hashing

Student passwords are stored using the application's password-hashing utility.

One Vote Per Student

The database enforces a unique student and election vote record.

Time-Controlled Elections

Elections are available according to their configured start and end times.

Automatic Results

Vote totals are calculated from recorded votes after an election ends.

No-Cache Voting Pages

Voting responses use no-store cache headers to reduce stale-page behavior.

Admin Management

Manage elections, candidates, and student records through the admin interface.

About VoteEase

VoteEase is an academic mini project demonstrating digital voting logic using Flask and SQLite, with authentication, backend validation, election management, and one-vote enforcement.
